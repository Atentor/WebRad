## Cause 1: source formatting

Each release job identified exactly these files:

- `packages/component-registry/src/registry.ts`: the condition validating the
  event detail type argument suffix needs a line break.
- `packages/language/src/generator.ts`: the conditional array containing the
  repeating-row alias needs multiline formatting.

Applied the repository's installed Prettier with `--write` to those files. The
diff changes whitespace only. The formatting gate and workflow ordering remain
intact.

## Cause 2: missing generated document in the existing test

The failing case in `packages/language/tests/language.test.ts` is
`provides a real typed event, native completions and invalid-member diagnostics
for every registered Interaction`.

Its expected 124 invalid-member diagnostics (TypeScript 2339) became 125
diagnostics, with one additional module-resolution error (2307), on both hosts.

Source inspection ties the extra diagnostic to the new Data Grid metadata:
`OnCellClick` declares `eventDetailTypeArgumentSuffix: 'RowValue'`.
`ensureEventHandler` consequently emits a reference such as
`import("./Audit.generated").Component1RowValue`. The old virtual language-service
fixture provided only `Audit.ts` and runtime declarations, leaving that module
absent. The hosted logs report the diagnostic code rather than its full message;
the missing module identification follows from this source-level dependency.

The fixture now creates an Audit page from the existing complete component
model, names its component instances consistently with the handler requests,
and supplies `Audit.generated.d.ts` through the real `generatePageTypings`
implementation. This provides the Data Grid row alias with the existing
`unknown` fallback when no API response contract is saved. It keeps generated
document dependencies representative of the production language environment.

The existing test still audits every registered Interaction, expects exactly
one invalid-member diagnostic per event, and checks native member completion
and parameter hover. No diagnostic is filtered, accepted as an extra error, or
suppressed. No new test suite was added.
